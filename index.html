Celestial Lattice Scatterer

What the controls mean
3D mode: shows the full cubic lattice and the true spatial trajectory.
2D mode: uses a planar square lattice and solves the corresponding two-dimensional scattering problem.
Spacing a: distance between neighboring lattice-sphere centers.
Obstacle radius: radius of each fixed spherical scatterer.
Projectile radius: radius of the moving ball. Collision occurs when center-to-center distance reaches the sum of the two radii.
Speed v: initial speed. It stays constant after perfectly elastic reflections, so it changes time-of-flight but not the geometric path.
Angle θ: initial direction angle in the x-y plane, measured from +x.
Collisions: number of collision events to calculate.
Lattice half-extent: number of lattice cells from the origin in each direction.
Animation: delay between displayed collision segments.
Run simulation: recomputes the trajectory and starts the cinematic particle-following animation from the origin.
Step: advances one collision at a time and reveals the path reached so far.
Reset: returns the projectile to the origin and restores interactive camera control.
Physics: collisions are perfectly elastic and specular against fixed scatterers, so speed is conserved while direction changes.

A fixed cubic or planar lattice of spherical scatterers. The projectile undergoes perfectly elastic, specular reflections and we record its location after each collision.
